# SelfCheckIn Frontend

TSX-basiertes React-Frontend auf Vite-Basis.

## Voraussetzungen

- Node.js 20+ (empfohlen)
- npm

## Schnellstart

```bash
npm install
npm run dev
```

## Wichtige Skripte

- `npm run dev` - startet den lokalen Dev-Server
- `npm run build` - TypeScript-Check plus Production-Build
- `npm run preview` - zeigt den gebauten Stand lokal an
- `npm run typecheck` - reiner TypeScript-Check

## Struktur

- `src/App.tsx` - Startseite mit Basisformular
- `src/types/forms.ts` - erste Form-Typen
- `vite.config.ts` - Vite-Konfiguration
